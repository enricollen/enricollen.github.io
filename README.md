# enricollen.com

Source for my personal site and blog, built with [Jekyll](https://jekyllrb.com/) and the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme, deployed via GitHub Actions to [enricollen.com](https://enricollen.com).

## About me

I'm Enrico Nello, an AI Engineer based in Italy with an MSc in Artificial Intelligence & Data Engineering (University of Pisa). This site is where I write up personal projects, talks, and things I've learned along the way — mostly AI/ML, agents, and the occasional hardware build.

- 🌐 [enricollen.com](https://enricollen.com)
- 💻 [GitHub](https://github.com/enricollen)
- 💼 [LinkedIn](https://www.linkedin.com/in/enriconello)

## Running locally

```console
$ bundle
$ bundle exec jekyll s
```

Site builds and deploys automatically on push via `.github/workflows/pages-deploy.yml`.
